# Prism.SSGI

Single-bounce screen-space global illumination for Space Engineers. Sampling follows SSILVB; denoising is a modified SVGF loop.

This plugin is an **Anomaly shader pack**. It does not replace Keen’s shader compiler or own GBuffer Target3.

## Requirements

- [Anomaly Shader Framework](https://github.com/PhoenixTheSage/Anomaly) (`A9C29274-E447-49EE-881B-C980E6D190FD`). Pulsar auto-enables it via `DependencyIds`.
- Optional: [Rich HUD Master](https://steamcommunity.com/sharedfiles/filedetails/?id=1965654081) for in-game settings under **Anomaly Shaders → SSGI → Settings**. The Pulsar config dialog (`OpenConfigDialog`) is the fallback when Master is not in the world.

## What it does

Each frame, after lighting (`AfterLighting`, once `Scheduler.Done` has published catalog `velocity` / `linearDepth` / `hiZ`):

1. C# BeforeFullscreen writes Trace uniforms, `SetEnabled`, and `SetScale` (Low = 1/4, Medium/High = 1/2). Catalog `litMips` is generated by Anomaly when Trace is live (`RequestLitMips(3)`).
2. A data-driven fullscreen program (`Fullscreen/AfterLighting/Trace.hlsl`) traces noisy GI at that scale (`PublishOnly` → `pass.prism.ssgi.trace`). Samples t7 `litMips` and t8 `hiZ`.
3. C# SVGF (temporal + à-trous) runs at pass size (`DrawFullscreenQuad` with the pass viewport — Keen’s no-viewport path is screen-sized and would stretch GI) and upsamples additively into `LBuffer`. Temporal reprojects with catalog velocity (full-res pixel delta) and inflates variance on short history so sparse SSILVB hits smear while the camera moves.

Anomaly skips HDR-slot fullscreen and owned passes on LCD / TargetView / TargetCamera. Motion uses Anomaly’s render-resolution **RG16F** velocity (`previousPixel = currentPixel + motion`). Depth compares catalog **linearDepth**, not hardware depth.

## GPU cost

This is a heavy pass. Slices, steps, and resolution scale dominate. Low traces at quarter-res (4 steps, 2 à-trous). Medium/High use half-res. Trace marches in **full-res** pixels (`AnomalySceneUvOffset`); the pass RT is only pixel cost. Use the presets when FPS drops.

## Config

Persisted at `%UserDataPath%/Storage/Prism/ssgi2.json`. Rich HUD setters mark dirty; flush from `Plugin.Update` after ~400 ms. The MyGui dialog saves on **Save**.

**Show Status** (Pulsar config footer, Rich HUD **SSGI → Settings** and **SSGI → Status**) reports compile, Anomaly bind, pass size, and the last skip reason. If Trace is missing, Anomaly Status lists `prism.ssgi.trace!compile` and `Anomaly.debug.log` has the FXC line.
